# KnowMe Frontend Engineering Case Study (Next.js)

KnowMe - демонстрационный frontend-проект, сфокусированный на
архитектуре, качестве кода, тестируемости и работе с серверными данными
в SSR-приложении на Next.js.

Проект используется как инженерный showcase, а не как коммерческий
продукт.

------------------------------------------------------------------------

## 🎯 Цели проекта

-   Спроектировать масштабируемое SSR-приложение на **Next.js**
-   Выстроить прозрачную и поддерживаемую архитектуру без
    over-engineering
-   Разделить бизнес-логику, UI и инфраструктурные слои
-   Обеспечить строгую типизацию и контроль качества
-   Реализовать взаимодействие с API и серверным состоянием
-   Покрыть ключевые участки системы unit и integration-тестами

------------------------------------------------------------------------

## 🧱 Архитектура

Проект построен по **feature-oriented подходу** с явным разделением
ответственности между слоями.\
Архитектура адаптируется под масштаб проекта и не доводится до FSD,
чтобы избежать избыточной сложности.

### Основные слои

-   `pages/` --- маршрутизация и SSR, страницы и API Routes
-   `pages/api/` --- backend-эмуляция через Next.js API Routes (auth,
    mentors, categories, messenger, user)
-   `components/` --- бизнес-компоненты по доменам
-   `ui-components/` --- переиспользуемые UI-элементы
-   `server/` --- серверная бизнес-логика, mock-данные и утилиты
-   `api/` --- клиентский API-слой
-   `providers/` --- глобальные провайдеры
-   `types/` --- DTO и контракты данных
-   `utils/` --- shared-утилиты

------------------------------------------------------------------------

## 🔌 Работа с данными

-   Клиент: `axios` + `react-query`
-   Backend: Next.js API Routes
-   Серверная логика покрыта тестами
-   Конфигурация API задаётся через переменные окружения
